# Сокращение URL #

* Автор: Noelia Ruiz Martínez

Это дополнение используется для сокращения адресов URL в NVDA с помощью [is.gd][1].

## Диалог сократить URL ##

Перейдите в меню NVDA, подменю инструментов, и активируйте пункт сократить URL.

В качестве альтернативы вы можете назначить жест в диалоге жестов ввода NVDA.

Диалог Сокращения URL включает в себя следующие элементы управления:

* Список для выбора одного из сохранённых URL. В этом списке нажмите shift+tab для поиска и tab для нажатия одной из следующих кнопок.
* Скопировать сокращённый URL. Это также можно активировать, нажав Enter в списке URL.
* Окно только для чтения отображает подробную информацию о выбранном адресе URL.
* Набор элементов управления для сокращения URL: Укажите новый URL; при желании вы можете задать отображаемое имя и пользовательский суфикс для сокращённого URL. Наконец, нажмите кнопку "Сократить URL".
* Переименовать: открывает диалог для ввода нового названия для отображения выбранного URL в списке.
* Удалить: открывает диалог для удаления выбранного URL.
* Удалить сохранённые URL: открывает диалог для удаления сохранённых URL из папки конфигурации.
* Закрыть.

## Изменения для 8.0.0 ##

* Добавлено поле только для чтения с подробной информацией о выбранном URL.

## Изменения для 5.0.0 ##

* Новый диалог для ввода URL заменён набором элементов управления в главном диалоге, позволяющим установить фокус на соответствующем поле для исправления возможных ошибок.

## Изменения для 2.0.0 ##

* Параметр сокращения  URL не будет отображаться несколько раз в подменю инструментов при перезагрузке плагинов.
* В диалоге нового URL есть поле для ввода пользовательского суффикса для сокращённого URL.

## Изменения для 1.0.0 ##

* Первоначальная версия.
